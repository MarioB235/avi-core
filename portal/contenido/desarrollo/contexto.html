Qué es AviCore

Plataforma de gestión operativa para avícolas de gallinas ponedoras (MVP).

Seleccionar galpón → cargar dato operativo → guardar → dashboard/reportes (tiempo real si aplica)

Stack: Laravel 13, PostgreSQL, Livewire 4, Tailwind 4, Alpine.js (Livewire), PWA instalable (MVP, sin offline completo), Reverb, Echo (Reverb/Echo en fases posteriores).

Contrato de ejecución

Ejecutar de punta a punta sin «¿procedo?». Preguntar solo si: dato crítico faltante, operación destructiva no autorizada, conflicto entre documentación, tarea contra reglas del proyecto.

Clasificación: feature | fix | refactor | docs | style | chore | hotfix

Principios no negociables

Multiempresa (empresa_id) · Policies/Gates · negocio en Services/Actions · anulación con motivo · auditoría crítica · UI verde/agro sin inline · un cambio conceptual → references/ del skill dueño + línea en portal/CHANGELOG.md.

Detalle: avicore-negocio/references/reglas.md

Flujo por módulo

1. Skill + references del módulo  2. Pantalla mínima  3. Migración/modelo  4. Livewire
5. Action/Service  6. Permisos  7. Validaciones  8. Auditoría/eventos si aplica
9. Probar PC y móvil  10. Actualizar reference del skill dueño si cambió contrato

Acceso en desarrollo (/login)

Con AVICORE_DEMO_LOGIN=true fuera de production: solo selector Perfil (sin documento ni contraseña en pantalla). El ingreso usa usuarios demo del seed; si falta empresa DEMO o algún usuario de role_documentos, /login muestra aviso (título «Todavía no podés entrar»), deshabilita el botón de ingreso y, si intentan enviar, el mismo texto en demoRole (MESSAGE_DEMO_SEED_MISSING, lenguaje para quien usa la app, sin comandos de terminal). En entorno local la alerta añade la pista migrate --seed para desarrolladores. Primera vez en tu PC: php artisan migrate --seed. Con flag en false o en producción: login normal documento + contraseña.
