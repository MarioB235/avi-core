5 — Commit, push y PR requiere autorización

Cuando querés publicar la rama; incluye verificaciones y PR.

Autorizo explícitamente en AviCore: commit, push y creación de pull request.

Seguí el skill avicore-git-pr. Flujo:

1. Revisión local: git status, git diff, confirmar que no hay secretos (.env).
2. Verificaciones: php artisan test y npm run build (si aplica).
3. Commit Conventional Commits (feat/fix/refactor/chore/docs/test/style) y git push -u origin [rama].
4. Crear la PR con MCP user-github (herramienta create_pull_request). Si MCP no está disponible, usar gh pr create.
5. Cuerpo de la PR con la plantilla del proyecto (Resumen, Objetivos, Cambios técnicos, Criterios AviCore, Verificación, Documentación).
