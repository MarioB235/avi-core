Comandos locales — raíz del proyecto referencia, no mensaje

Ejecutá en la carpeta donde está artisan (PowerShell, CMD o bash). App en http://localhost:8000 (redirige a /login) — no abras :5173 en el navegador (es solo Vite). Fuente maestra: docs/reference/arranque-local.md. Git: vendor/, node_modules/, public/build/ y .vite/ no se suben al repo — si el IDE muestra miles de cambios, revisá que la carpeta abierta sea la raíz de AviCore (donde está artisan) y que no esté activado «mostrar ignorados» en control de código.

Qué querés hacer Comando Notas

Arranque manual (equivalente a primera vez)

Si preferís paso a paso en lugar de composer setup:

composer install
cp .env.example .env
php artisan key:generate
npm install
php artisan migrate
php artisan db:seed
npm run build

Verificar antes de PR

php artisan test
npm run build

Corregir / refrescar el proyecto local

Cuando fallan deps, estilos rotos o config desactualizada:

composer install
npm install
php artisan migrate
php artisan config:clear
php artisan cache:clear
npm run build

cp .env.testing.example .env.testing
